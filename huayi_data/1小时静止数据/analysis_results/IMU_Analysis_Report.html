指标定义说明
指标名称定义计算方法标准依据
零偏不稳定性 (BI) Allan 偏差曲线中的 flicker/pink rate-noise 平台系数 识别3个原曲线连续点：|拟合斜率|≤0.10、max|相邻斜率|≤0.15、log10残差RMS≤0.03；B = σ平台 / 0.66428；平台识别通过不等于规格可比，所有平台均需另行匹配厂家测试条件与定义，边界平台另有边界限制 噪声模型关系与工程判据；非通用 MEMS 合规声明
最低 ADEV 等效参考 可信平台不明显时仍可报告的受约束工程参考；不是 BI 仅在 tau≥1 s 且 n_terms≥20 中取最低 ADEV，再除以 0.66428；同时报告 tau、n_terms、局部斜率和边界状态 本项目工程判据，非标准强制门槛；不用于规格合格判定
10 s 分段均值标准差 10 秒非重叠窗口均值的总体标准差 按10 s分段，计算各段均值的 std(ddof=0) 工程统计量，条款适用性需另行核对
角度随机游走 (ARW) 陀螺仪白噪声引起的角度积分随机游走 ADEV 在 0.1～10 s 区间进行 log-log 斜率拟合，外推至 1 s Allan 噪声模型参考
速度随机游走 (VRW) 加速度计白噪声引起的速度积分随机游走 ADEV 在 0.1～10 s 区间进行 log-log 斜率拟合，外推至 1 s Allan 噪声模型参考

Allan 偏差常用单位换算参考表
参数计算单位换算公式目标单位
加速度计 VRW 系数 N
(Velocity Random Walk)		 m/s/√s（即 (m/s²)·√s） = Nm/s/√s
= N × 60m/s/√h
= N × 1×10⁶ / 9.80665μg·√s
加速度计 BI/等效参考/BS
(Bias / reference / 10 s segment statistic)		 m/s² = 数值 / 9.80665g
= 数值 × 1×10³ / 9.80665mg
= 数值 × 1×10⁶ / 9.80665μg
陀螺仪 ARW 系数 N
(Angle Random Walk)		 °/√s = N × 60°/√h
= N × π / 180rad/√s
= N × π / 3rad/√h
条件等效单边白噪声 ASD 仅限白速率噪声、0..fs/2 单边 PSD 约定 = √2 × N(输入速率单位)/√Hz
由 ADEV-RW 推导；不是直接谱估计，也不自动等同厂家噪声密度
陀螺仪 BI/等效参考/BS
(Bias / reference / 10 s segment statistic)		 °/s = 数值 × 3600°/h
= 数值 × π / 180rad/s
= 数值 × 20πrad/h
📖 说明：
1. 输入同量纲：ADEV 的单位由输入速率序列决定，图轴不因结果换算而改变。
2. BI：仅对识别出的近零斜率平台计算，关系为 B = σ平台 / 0.66428。
3. 最低 ADEV 等效参考：只是受约束的替代参考，不是正式 BI，不用于规格判定。
4. BS：本程序显示的是10 s非重叠分段均值标准差（ddof=0）这一工程统计量。
5. 单边 ASD 条件等效：√2×N 仅适用于白速率噪声和0..fs/2单边PSD约定；不是直接谱估计，也不自动等同厂家噪声密度。
6. 1 g = 9.80665 m/s²；1 mg = 0.001 g；1 μg = 0.000001 g。
